# Movie Rental Analysis

## Project Overview
Performed end-to-end data analysis on a movie rental dataset by integrating 16 relational tables to explore rental trends, customer behavior, film performance, and revenue insights.

## Tools & Technologies
- **SQL:** Data cleaning, joins, aggregations, and analytical queries
- **Microsoft Excel:** Data cleaning, data organization, and exploratory analysis
- **Power BI:** Interactive dashboards, KPI tracking, and data visualization

## Key Highlights
- Worked with 16 relational tables to analyze movie rental data.
- Cleaned and prepared data to improve consistency and reliability.
- Performed SQL analysis to identify rental patterns and business insights.
- Conducted Excel-based analysis to explore trends and summarize findings.
- Built interactive Power BI dashboards to visualize rental performance and key metrics.

## Key Learnings
Strengthened practical skills in data cleaning, SQL querying, exploratory data analysis, and business intelligence reporting.
End-to-end movie rental data analysis using SQL, Excel, and Power BI across 16 relational tables.
